# 2026-10-13 播放界面统一实施记录

## 已确认的需求

以原动漫播放器为唯一界面标准，统一电视剧和电影进入播放后的布局、选集、控制栏和通用操作。影视没有数据支持的弹幕、评论、下载和一起看隐藏；来源、收藏、历史和续播保留。交付 Windows、Android 手机、Android 电视三个包。影视频道和作品详情保持现有流程。

## 实现

- `PlayerControlsController` 持有唯一的播放、面板、调试、截图和定位状态；原 `PlayerController` 作为动漫包装，保留原公开接口及弹幕、SyncPlay 副作用。
- `PlayerPresentationContext` 与动漫适配器隔离作品业务；`PlayerItem`、控制面板、视频画面及详情使用通用层，原动漫布局、侧栏、选集、手势和键鼠控制为三类内容共享。
- `SourcePlaybackSession` 使用 `MediaRef`、来源线路和播放项稳定 ID，不构造 Bangumi 身份，不迁移已有影视存储。原解析、请求头、平台解码回退、串行切集和 Android 恢复确认继续生效。
- 共用宿主持续挂载，只绑定一次带 owner 的音频会话，并保留一个状态时钟。影视每五秒保存进度，切集、后台和退出另行保存；恢复确认前不覆盖旧记录，电影不自动跳版本。
- 影视能力显隐覆盖全部控件布局、快捷键、电视操作和 Android 原生画中画；macOS 系统播放菜单同步隐藏无支持的弹幕入口，本轮不构建 Apple 包。
- 解析、切集、恢复、失败和退出阶段统一限制定位操作；恢复中允许暂停和取消。电视媒体暂停键与播放按钮保留暂停路径。
