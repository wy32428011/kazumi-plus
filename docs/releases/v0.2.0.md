# Kazumi Plus v0.2.0

发布日期：2026-11-26
对比基线：`v0.1.0`..`v0.2.0`

## 新增功能

- **内容优先智能选源与多源联邦发现**：电影与电视剧频道由“先选采集站”升级为“先选作品”，支持跨源联邦发现、聚合搜索结果去重折叠、音轨/配音版本分桶与自动推荐最优片源，并支持跨源续播与收藏状态联动。
- **片源实测健康评估与播中自动容灾切源**：新增片源与 CDN 实测健康库、卡顿监控与播中故障自动切源横幅，并在设置中提供「片源健康」状态页；同时通过统一流量守卫与 MacCMS 载荷缓存（将发现→详情→播放列表 3 次请求合并为 1 次）显著降低重复请求与风控风险。
- **「银盐放映室」全新主题与多端 UI 视觉重设计**：统一桌面、移动端与大屏色彩体系、导航布局与详情/放映厅视觉层次，优化热门页筛选面板与影视首页卡片呈现。
- **播放器画质切换与本地 HLS 代理增强**：桌面控制栏、手机更多选项与电视控制层均支持基于真实解码视频轨的清晰度选择（显示实际分辨率与码率），内置本地 HLS 代理与常规/低内存双档缓冲策略。
- **弹幕与检索回退增强**：新增 Bilibili 弹幕回退支持与 Bangumi 搜索镜像/ECH 多级回退机制，提升无凭证或受限网络环境下的检索与弹幕可用性。
- **影视预置源与投屏能力扩展**：新增多个经验证的影视预置规则源（含 `4kav`、`haohua`、`hongniu`、`huya`、`ikun`、`iqiyi`、`jinying`、`maoyan`、`xinlang`、`zy360` 等），完善局域网 SSDP 投屏设备发现与三端系统权限声明。
- **本地一键打包工具链**：新增 Windows 一键打包入口与脚本支持，方便本地生成便携 ZIP、Windows 安装包及 Android APK。

## 修复与优化

- 修复单码率片源清晰度弹窗无法直接切源的问题，统一播放器切源与画质切换交互。
- 优化 Android TV 10-Foot 播放控制：支持超 1 小时影片 `HH:MM:SS` 时间码显示、5 秒无操作自动隐藏控制层（暂停时保持常驻）及大屏焦点交接。
- 优化 macOS 系统菜单与全端能力控制：无弹幕数据的影视内容在 macOS 原生菜单及各端播放器面板中自动隐藏弹幕入口。
- 优化片源规则文本清洗（修复多层 HTML 实体解码与异常年份格式）并保护预置规则升级时用户自定义的域名与请求头。

## 已知限制与说明

- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。
