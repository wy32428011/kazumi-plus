# Kazumi Plus v0.2.4

发布日期：2026-11-28
对比基线：`v0.2.3`..`v0.2.4`

## 新增功能

- **播中「本地 4K 超分增强」抽屉与画质面板联动**：
  - 新增独立 4K 超分增强控制面板（桌面端与 Android TV 为右侧暗房抽屉，移动端为底部面板），支持在播放过程中实时切换「关闭 / 4K 效率档 / 4K 质量档」并即时刷新超分参数，方便实时对比增强前后画质。
  - 在播放器清晰度/片源切换面板中内嵌「本地 4K 超分增强」快捷分段卡片与「详细设置」入口，支持动漫、电视剧、电影三频道统一呼出。
- **细节锐化增强（Adaptive Sharpen）**：
  - 内置 `adaptive-sharpen.glsl` 着色器及第三方许可声明（`licenses/shaders/THIRD_PARTY_NOTICES.md`），并在「设置 → 4K 超分辨率与画质增强」及播中面板中新增独立开关（默认开启），超分放大后进一步强化边缘与纹理清晰度。

## 修复与优化

- **升级 4K 超采样输出尺寸策略**：
  - 优化 `computeTargetOutputSize`：桌面端、Android TV 以及「4K 质量档」统一以长边 `3840` 为上限计算目标输出尺寸（最高 2×，原生高分片源自动跳过），修复窗口模式或 1080P 显示器下因物理视口较小导致无法触发超分着色器的问题。
- **精调动漫与影视超分档位模型及交互文案**：
  - 影视「4K 效率档」采用 `FSR + 细节锐化 + 去色带`，「4K 质量档」采用 `FSRCNNX + 细节锐化 + 色度增强`；动漫档位统一采用 Anime4K 线条增强链路提升至 4K。
  - 统一桌面端、移动端、Android TV 与设置页的 4K 超分标签及引导文案，并扩充 `test/super_resolution_plan_test.dart` 单元测试覆盖。

## 已知限制与说明

- 超分辨率需要启用硬件解码；Android / Android TV 设备若开启后未生效，请在播放设置中将视频渲染器切换为 `gpu` 或 `gpu-next`（`mediacodec_embed` 不支持输出放大）。
- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。
