## 已知限制与说明

- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。

## 安装包清单

- `Kazumi-Plus-<version>-windows-x64-setup.exe`（Windows 安装版，推荐）
- `Kazumi-Plus-<version>-windows-x64.zip`（Windows 绿色版）
- `Kazumi-Plus-<version>-android-mobile-arm64.apk`（Android 手机版）
- `Kazumi-Plus-<version>-android-tv.apk`（Android TV 版）
- `Kazumi-Plus-<version>-macos.dmg`（macOS 通用包）
- `Kazumi-Plus-<version>-ios.ipa`（iOS 未签名包）
- `SHA256SUMS.txt`（全部安装包校验和）
