# Kazumi Plus v0.2.5

发布日期：2026-11-29
对比基线：`v0.2.4`..`v0.2.5`

## 新增功能

- **GitHub 到 Gitee 自动代码与标签镜像工作流**：
  - 新增 `.github/workflows/sync-gitee.yaml`，推送任意分支或标签到 GitHub 后自动同步至 Gitee 对应分支与标签，并支持手动 `workflow_dispatch` 全量同步或指定历史 Release 补同步。
- **全平台发版自动同步 Gitee Release**：
  - 在 `.github/workflows/plus-release.yaml` 中新增 `sync-gitee-release` 阶段，并新增可复用脚本 `scripts/sync_gitee_release.py`；GitHub Release 发布完成后，自动将全平台构建产物、`SHA256SUMS.txt` 与版本更新说明同步至 Gitee 发行版，保证双平台安装包完全一致。

## 修复与优化

- **完善 Gitee Release 同步兼容性与测试覆盖**：
  - 兼容历史标签通过 `workflow_dispatch` 重跑时的脚本检出与对应标签发行说明提取（`git show refs/tags/<tag>:<notes_path>`）。
  - 为 Gitee Release 创建接口增加 `target_commitish` 自动回退为标签名的兼容处理，并在 `scripts/test_sync_gitee_release.py` 中补充本地 Mock HTTP 单元测试。

## 已知限制与说明

- 超分辨率需要启用硬件解码；Android / Android TV 设备若开启后未生效，请在播放设置中将视频渲染器切换为 `gpu` 或 `gpu-next`（`mediacodec_embed` 不支持输出放大）。
- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。
