# Kazumi Plus v0.2.3

发布日期：2026-11-28
对比基线：`v0.2.2`..`v0.2.3`

## 新增功能

- **分频道智能超分辨率与画质增强管线**：
  - 支持按内容类型自动匹配超分模型（支持在设置中切换「自动（按频道）」「动漫优先」「影视真人优先」）：
    - **动漫模型**：效率档使用轻量 Anime4K，质量档升级为 `ArtCNN`（内置 `ArtCNN_C4F16` / `ArtCNN_C4F32`）。
    - **影视真人模型**：效率档使用 `FSR` + 去色带，质量档使用 `FSRCNNX`（`FSRCNNX_x2_8-0-4-1` / `FSRCNNX_x2_16-0-4-1`）+ `KrigBilateral` + 去色带。
  - 新增对应 GLSL 着色器与第三方开源许可声明（`licenses/shaders/THIRD_PARTY_NOTICES.md`）。
- **全平台目标输出分辨率放大（最高 4K / 2×）**：
  - 结合源视频尺寸与当前物理视口自动计算目标输出尺寸（长边上限 3840、最高 2× 放大、保持宽高比与偶数对齐），源分辨率已达高位时自动跳过超分以节省功耗。
  - 引入 `third_party/media_kit_video` 本地补丁：补齐 Android / Android TV 端 `AndroidVideoController.setSize()` 输出 Surface 放大能力，并消除桌面与 iOS 端 `videoParams` 回调覆盖显式输出尺寸的竞态。
- **高丢帧自动降档与增强型设置/监控面板**：
  - 「设置 → 超分辨率与画质增强」新增内容模型策略、去色带开关、输出分辨率放大开关与高丢帧自动降档开关（连续高丢帧时自动从质量档降至效率档或关闭）。
  - 播放器「视频详情」面板新增「源分辨率 → 输出分辨率」展示、当前画质增强方案摘要、丢帧数统计与实时生效的着色器链信息。

## 修复与优化

- **着色器资产按 SHA-256 增量同步**：升级 `ShaderAssetService`，版本升级后自动比对哈希并覆盖更新过期的本地 `.glsl` 着色器文件，不再因同名文件已存在而跳过更新。
- **同步生成代码与分析配置**：重新生成受影响的 MobX 控制器代码，并在静态分析配置中排除 `third_party/**`。

## 已知限制与说明

- 超分辨率需要启用硬件解码；Android / Android TV 设备若开启后未生效，请在播放设置中将视频渲染器切换为 `gpu` 或 `gpu-next`（`mediacodec_embed` 不支持输出放大）。
- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。
