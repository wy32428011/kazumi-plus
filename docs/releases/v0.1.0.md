# Kazumi Plus v0.1.0

发布日期：2026-11-25

## 新增功能

- 支持动漫、电视剧、电影三频道浏览、检索、详情、收藏、历史与断点续播，应用标识与本地数据目录与原版 Kazumi 完全隔离。
- 新增统一播放器架构，三类内容共用播放控制、选集、画质切换、投屏与手势体验，并按内容能力自动隐藏无数据支持的弹幕/评论入口。
- 新增 Android TV 专属端型，支持遥控器焦点导航、规则检索与大屏播放控制。
- 新增 macOS 与 iOS 多端构建支持，覆盖 Windows、Android 手机、Android TV、macOS、iOS 五端发行。
- 新增基于 GitHub Releases 的独立版本检测与客户端内更新支持：支持按平台与端型自动匹配安装包（Windows `.exe`/`.zip`、Android 手机/TV `.apk`、macOS `.dmg`），展示版本更新日志并下载安装。

## 修复与优化

- 修复 Android TV 侧边栏在内容边界处的焦点恢复与遥控器搜索键盘触发问题。
- 优化规则库搜索确认交互与导入错误提示。
- 优化多端构建与打包流程：对齐 Android flavor 产物命名、过滤多余原生库、完善 Windows Inno Setup 安装程序与 macOS DMG 挂载校验。

## 已知限制与说明

- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。

## 安装包清单

- `Kazumi-Plus-v0.1.0-windows-x64-setup.exe`（Windows 安装版，推荐）
- `Kazumi-Plus-v0.1.0-windows-x64.zip`（Windows 绿色版）
- `Kazumi-Plus-v0.1.0-android-mobile-arm64.apk`（Android 手机版）
- `Kazumi-Plus-v0.1.0-android-tv.apk`（Android TV 版）
- `Kazumi-Plus-v0.1.0-macos.dmg`（macOS 通用包）
- `Kazumi-Plus-v0.1.0-ios.ipa`（iOS 未签名包）
- `SHA256SUMS.txt`（全部安装包校验和）
