# Kazumi Plus v0.2.1

发布日期：2026-11-28
对比基线：`v0.2.0`..`v0.2.1`

## 修复与优化

- **修复搜源与播中切源信号量重入死锁**：在 `SourceTrafficGuard` 中新增基于 `Zone` 的重入保护，移除 `PluginSearchService` 与 `AnimePlayerPresentation` 外层重复套壳，统一由底层 `RuleEngine` 实施并发与限频治理，并按插件粒度管理取消令牌（`RuleCancelToken`），修复并发搜索或切源时的阻塞与取消识别问题。
- **加固独立版自动更新与完整性校验**：
  - 统一校验并归一化 `KAZUMI_PLUS_UPDATE_URL`，显式拒绝指向原版上游 `Predidit/Kazumi` 的更新地址，并从独立更新接口自动推导关于页「更新日志」发布页链接。
  - 当 Release 资产未提供 `digest` 字段时，自动回退读取同版本的 `SHA256SUMS.txt` 进行安装包完整性校验，并补充更明确的下载错误提示。
  - 完善首次启动引导页与设置页的独立版更新方式文案与状态展示。
- **构建脚本与发版工作流更新地址强校验**：新增 `scripts/update_url.ps1`，在 Windows/Android/macOS/iOS 本地与 GitHub Actions 构建中统一自动解析并强制核验 `KAZUMI_PLUS_UPDATE_URL` 注入结果；正式版 Release 重复上传更新时自动保持 `--latest` 标记。

## 已知限制与说明

- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。

## 安装包清单

- `Kazumi-Plus-v0.2.1-windows-x64-setup.exe`（Windows 安装版，推荐）
- `Kazumi-Plus-v0.2.1-windows-x64.zip`（Windows 绿色版）
- `Kazumi-Plus-v0.2.1-android-mobile-arm64.apk`（Android 手机版）
- `Kazumi-Plus-v0.2.1-android-tv.apk`（Android TV 版）
- `Kazumi-Plus-v0.2.1-macos.dmg`（macOS 通用包）
- `Kazumi-Plus-v0.2.1-ios.ipa`（iOS 未签名包）
- `SHA256SUMS.txt`（全部安装包校验和）
