# Kazumi Plus v0.2.2

发布日期：2026-11-28
对比基线：`v0.2.1`..`v0.2.2`

## 新增功能

- **全频道统一弹幕支持（动漫 / 电视剧 / 电影）**：
  - 抽象统一弹幕能力接口 `PlayerDanmakuFeatures`，让电影与电视剧播放会话（`SourcePlaybackSession`）与动漫播放页共用同一套弹幕渲染层、开关、样式设置、手动切源、倍速同步及画中画状态联动。
  - 桌面端、移动端与紧凑布局控制栏及更多菜单均按 `PlayerDanmakuFeatures` 能力开放弹幕控制（影视仍按能力隐藏无数据支持的 Bangumi 评论与一起看入口）。
- **自定义兼容弹幕 API 与弹弹Play 凭证设置**：
  - 在「设置 → 弹幕设置」中新增「自定义弹幕 API」（支持兼容弹弹Play v2 接口与带 token 路径，自动校验并归一化 `http/https` 地址）及「弹弹Play API 凭证」（AppId / AppSecret）配置项。
  - 用户在设置页填写的弹弹Play 凭证优先于编译期注入与环境变量，保存后即时生效，无需重新编译。
- **三源聚合弹幕搜索与分级自动回退**：
  - 自动加载弹幕按 **自定义弹幕源 → 弹弹Play（已配置凭证）→ B站公开弹幕** 顺序回退，无凭证环境下也能为动漫、电视剧和电影自动匹配公开弹幕。
  - 播放器「弹幕切换」面板改为并发聚合三类弹幕源，在结果列表中展示来源标识，并支持自定义源内联剧集解析。

## 修复与优化

- **影视/动漫弹幕标题清洗与匹配精度提升**：
  - 新增 `DanmakuApi.buildSearchCandidates` 与强化版关键词规范化逻辑，自动剔除来源标题中的集数、清晰度（如 `4K`、`HD`）、配音（如 `国语`）与括号年份等修饰后缀，按精准度生成多级检索词。
  - 优化 `BilibiliDanmakuApi` 候选作品与分集匹配：引入频道类型（番剧 / 电视剧 / 电影）亲和度评分、过滤二创/解说噪声标题；电影自动跳过预告片优先命中正片；剧集支持在 PV/预告前置时精准定位对应集号。
- **播放默认体验与控制器健壮性优化**：
  - 将「播放时默认开启弹幕」默认状态调整为开启，加载到弹幕后自动显示。
  - 在 `PlayerDanmakuController` 中增加 `hasCanvasController` 与安全的画布暂停/恢复封装，防止弹幕画布尚未挂载时的空状态异常；修复 `AnimePlayerPresentation` 注册 `onBeforeSeek` 时可能覆盖前置回调的问题。

## 已知限制与说明

- Windows 安装包（`.exe`）支持每用户覆盖安装并保留 `%APPDATA%\KazumiPlus` 用户数据；绿色版（`.zip`）需解压后手动替换。
- Android 手机版（`android-mobile`）与 Android TV 版（`android-tv`）为独立包名与签名，请按设备选择对应安装包。
- macOS 打包产物（`.dmg`）为 ad-hoc 签名，未公证，首次打开可能需要在系统设置中允许运行。
- iOS 打包产物（`.ipa`）为未签名包，需自行合法签名后安装，不支持应用内自动更新。
